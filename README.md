# 🧭 KJEI Campus Navigation System

A professional Smart Campus Navigation System developed for KJ's Educational Institute, Pune.

## 📌 Project Overview

The KJEI Campus Navigation System helps students, visitors, and faculty easily navigate the campus using an interactive digital map.

The system provides:

- 🗺 Interactive Campus Map
- 📍 Destination Selection
- 🧭 Route Navigation
- 🌐 Multi-language Support
- 🎨 Animated Welcome Screen
- 🏫 Department Navigation
- 📱 Responsive Design
